# Landing Page

A responsive static landing page created as part of my OASIS Infobyte Web Development & Designing Internship.

## About the Project

This project is a visually polished landing page for Wanko Coffee, a fictional coffee brand. It was built to practice HTML5 and CSS3 layout, responsive design, and user-friendly interface design.

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid

## Features

- Sticky navigation bar
- Navigation links
- Hero section with headline and call-to-action
- About section
- Features section
- Call-to-action section
- Responsive design for mobile and desktop
- Consistent color palette
- Footer with contact and social links
- Smooth navigation between sections
