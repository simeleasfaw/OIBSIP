# Simele Asfawesen - Portfolio

A modern, minimalist portfolio website showcasing the work and skills of a Software Engineering student.

## Overview

This is a personal portfolio website designed to present professional background, technical skills, and projects in a clean, modern aesthetic. The site features smooth navigation, dark mode support, and a responsive design that works seamlessly across all devices.

## Features

✨ **Modern Design**

- Clean, minimalist aesthetic with a warm color palette
- Professional typography using Google Fonts (DM Sans & Playfair Display)
- Smooth scrolling navigation and transitions

🌙 **Dark Mode**

- Toggle between light and dark themes
- User preference saved in localStorage for persistence
- Smooth theme transitions

📱 **Responsive Design**

- Mobile-first approach
- Adapts seamlessly to different screen sizes
- Flexible grid layouts

🎯 **Sections**

- **Hero Section** - Eye-catching introduction with profile image
- **About** - Personal introduction and interests
- **Skills** - Technical skills and technologies
- **Projects** - Showcase of work and projects
- **Contact** - Email and social media links

🔗 **Quick Navigation**

- Fixed navbar with smooth section linking
- Scroll-to-section functionality

## Technologies Used

**Frontend:**

- HTML5
- CSS3 (CSS Grid, Flexbox, Custom Properties)
- JavaScript (ES6+)

**Tools & Services:**

- Google Fonts for typography
- localStorage API for theme persistence

## Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- No installation or build process required

### How to Use

1. **View the Portfolio**
   - Open `index.html` in your web browser
   - Or deploy to a web hosting service

2. **Navigate the Site**
   - Use the navigation bar to jump to different sections
   - Click on section links to smoothly scroll to that area
   - Toggle dark mode with the moon/sun button

3. **Customize**
   - Replace `images/profile.jpg` with your own profile picture
   - Update content in `index.html` with your information
   - Modify colors in `style.css` by updating CSS custom properties

## Key Technical Features

### Dark Mode Implementation

- Uses CSS custom properties (CSS variables) for theme switching
- `data-theme` attribute on root element toggles between light and dark
- localStorage keeps user's preference across sessions

### Responsive Design

- CSS Grid for hero section layout
- Flexbox for navigation and skill grid
- `clamp()` function for fluid typography sizing
- Media queries for mobile optimization

### Smooth Scrolling

- HTML `scroll-behavior: smooth` for native smooth scroll
- Scroll margin on sections for proper spacing with fixed navbar
